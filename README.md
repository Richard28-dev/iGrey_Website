# iGREY HOLDINGS — Luxury Real Estate & Advisory

A bespoke, ultra-luxury real-estate web application engineered for **iGREY HOLDINGS**.

## Features

- **Cinematic Opening Animation**: Monogram reveal and smooth editorial transition into the residence showcase.
- **Hero Sanctuary**: Full-height responsive layout with modern typography and refined call-to-actions.
- **Curated Architectural Portfolio**: 3×2 listing grid featuring 4:3 photographs, custom badges, metadata tags, and quick-access catalogue links.
- **The iGrey Advantage & Difference**: High-trust pillar cards detailing verified representations, rent guarantees, and legal due diligence.
- **Interactive Service Directory**: Dynamic numbered rows with contextual architectural preview synchronization.
- **Integrated Enquiry Desk**: Bespoke advisory contact form with real-time feedback and direct partner desk coordinates.
- **Light & Dark Aesthetic Harmony**: Seamless transitions between deep obsidian noir and architectural gallery limestone palettes.

## Tech Stack

- **Framework**: React 18, TypeScript, Vite
- **Styling**: Modern CSS variables, Plus Jakarta Sans, Cormorant Garamond
- **Animations**: Framer Motion
- **Icons**: Lucide React

## Development & Deployment

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
```
